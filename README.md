# Panadería El Trigo Dorado

## 1. El proyecto

Panadería El Trigo Dorado es un sitio web desarrollado para una panadería local que busca mostrar sus productos, horarios de atención y medios de contacto en internet.

El objetivo del sitio es facilitar que los clientes conozcan los productos disponibles, consulten información importante y puedan realizar pedidos de forma rápida.

El público objetivo son personas que buscan productos de panadería artesanal y desean conocer la ubicación, horarios y precios del negocio.

## 2. Estructura

El proyecto está organizado de la siguiente manera:

```text
├── index.html
├── pedidos.html
├── README.md
├── css/
│   └── styles.css
├── images/
└── capturas/
```

### Etiquetas semánticas utilizadas

- header: contiene el nombre del negocio y la navegación principal.
- nav: agrupa los enlaces internos y externos del sitio.
- main: contiene el contenido principal de cada página.
- section: divide el contenido en bloques temáticos.
- article: representa cada producto de la panadería.
- footer: contiene la información de derechos de autor.
